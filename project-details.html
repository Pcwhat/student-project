Group 08 Main Project • Case Study

Student Project Showcase & Evaluation Platform

A responsive, high-performance academic web portal engineered to archive, search, and present student engineering capstone projects with real-time academic rubric evaluation, customizable theme engines, mechanical acoustics, and interactive project directories.

Explore Directory Evaluation Rubric

1. Academic Motivation & Problem Statement

In university engineering institutions, student capstone and Project-Based Learning (PBL) submissions are conventionally documented on physical paper binders, isolated personal flash drives, or fragmented local folders. This traditional workflow poses critical challenges:

  • Evaluation Bottlenecks: Faculty evaluators lack a unified, accessible digital dashboard to grade student submissions against transparent departmental rubrics.
  • Viva Examiner Friction: External viva panels cannot quickly examine technical code architectures, live prototypes, and component schematics during scheduled evaluation sessions.
  • Archive & Knowledge Gaps: Junior cohorts (1st, 2nd, and 3rd-year engineering students) have no institutional showcase to discover previous projects, examine faculty-verified standards, or build upon proven work.

To resolve these challenges, Group 08 engineered the Student Project Showcase & Evaluation Platform — a lightweight, zero-dependency academic web portal designed for Course DCSE0152 (Web Designing) and departmental capstone evaluations.

2. Core Architectural Pillars

  • Infinite Circular Flywheel Directory: Smooth inertia flywheel slider paired with multi-factor filtering by domain (IoT, Web, Automation) and academic year (1st, 2nd, 3rd, Final Year) with zero layout shifting.
  • Synthesized Web Audio Acoustics: Procedural sound generator utilizing the browser Web Audio API to produce authentic mechanical tactile feedback on slider notches and button presses without external audio assets.
  • Dual High-Contrast Design System: Two accessible themes — Warm Ivory Clay (default light) and Obsidian Charcoal Black (dark) — with manual root scaling (14px–20px) and typographic combinations.
  • Standardized Viva Rubric Matrix: Comprehensive grading breakdown aligned with departmental evaluation parameters: UI Design, Code Quality, Working Functionality, and Viva Defense.

3. Project Results & Testing

The platform was tested across desktop and mobile browsers (Chrome, Edge, Firefox, Safari) and achieved 100% responsive fluid layout scaling, sub-16ms smooth 60fps momentum animations, and full WCAG color contrast compliance across both Light and Dark themes.

Key Engineering Components

  • Semantic HTML5 & WCAG Accessibility: Native modal overlays, accessible ARIA radio-groups, proper tab semantics, and clean keyboard navigation.
  • CSS Custom Property Design Tokens: Three-layer variable token architecture ensuring instant, zero-flicker transitions between Warm Ivory and Charcoal Black.
  • Procedural Acoustics Generator: Dynamic Web Audio API biquad filters and exponential gain envelopes that synthesize mechanical clicks without external audio files.
  • Multi-Factor Search & Year Filter: Live regex word matching with highlight markers that seamlessly combines category and student academic year filters.

Core Web Audio Synthesizer Code

The procedural acoustic synthesizer powers mechanical feedback across all sliders and interactive elements:

MechanicalAudioEngine.js
JavaScript / Web Audio API 
// Group 08 - Procedural Web Audio API Sound Synthesizer
// Zero external audio files; 100% procedurally synthesized acoustics
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();

function playScrollTick(volumeScale = 1.0) {
  if (audioCtx.state === "suspended") audioCtx.resume();
  const now = audioCtx.currentTime;

  // High-frequency mechanical contact transient
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  const filter = audioCtx.createBiquadFilter();

  filter.type = "bandpass";
  filter.frequency.setValueAtTime(2400, now);
  filter.Q.setValueAtTime(4.2, now);

  osc.type = "sine";
  osc.frequency.setValueAtTime(1850, now);
  osc.frequency.exponentialRampToValueAtTime(320, now + 0.022);

  gain.gain.setValueAtTime(0.09 * volumeScale, now);
  gain.gain.exponentialRampToValueAtTime(0.0001, now + 0.028);

  osc.connect(filter);
  filter.connect(gain);
  gain.connect(audioCtx.destination);

  osc.start(now);
  osc.stop(now + 0.03);
}
